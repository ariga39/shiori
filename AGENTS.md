# AGENTS.md

## Changelog fragments (Towncrier)

Every PR carries exactly one fragment under `changelog.d/` named after its own
issue/PR number:

- User-visible changes: `<n>.<type>.md` where type is one of Towncrier's default
  types (`feature`, `bugfix`, `doc`, `removal`, `misc`).
- Test-only / internal / CI-only changes: the single waiver `<n>.no-changelog.md`
  with one line explaining why no user-facing entry is needed.

Never hand-edit `CHANGELOG.md` — it is generated by `towncrier build`. Numbers are
globally unique per issue/PR, so conflicts between parallel PRs cannot happen:
always use your own number, never renumber or reuse another PR's fragment.
Validate before pushing: `uv run python tools/changelog_check.py --dir . --base <merge-base>`.
